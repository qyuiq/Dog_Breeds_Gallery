# Промпты для лабораторной работы AI TDD

## Анализ задания

> Проанализируй требования лабораторной работы для DogBreeds: нужны 5 unit-тестов бизнес-логики, 3 интеграционных теста data-domain-view, 2 UI-теста и новая функция, разработанная по циклу Red-Green-Refactor. Предложи тестируемую архитектуру без Hilt/Dagger/Koin.

## TDD-функция поиска

> Добавь новую функцию поиска пород. Поиск должен игнорировать регистр, пробелы в начале и конце запроса, а пустой запрос должен вернуть весь список. Сначала создай падающий unit-тест, затем реализуй минимальный код, затем выполни рефакторинг без изменения поведения. Каждый шаг зафиксируй отдельным Git-коммитом на русском языке.

## Интеграционные тесты

> Напиши интеграционные тесты, которые проверяют путь данных от источника через репозиторий и use case до ViewModel: загрузка списка, фильтрация и изменение избранного. Не используй сеть или реальную БД: применяй fakes.

## UI-тесты

> Добавь два Compose UI-теста: пустое избранное показывает понятный текст, а список избранного отображает сохранённую породу. Тесты должны работать без реального API.
